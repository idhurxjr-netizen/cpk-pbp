# CPK PBP — Aplikasi Pesan Sederhana

## Deskripsi

Aplikasi pesan sederhana untuk Proyek CPK PBP. Pengguna dapat mendaftar,
masuk, mengelola kontak, dan bertukar pesan teks atau gambar.

## Teknologi

- Frontend: HTML, CSS, JavaScript murni
- Backend: PHP 8.4 murni
- Database: MariaDB 10.11
- Auth: JWT (php-jwt)
- Notifikasi: Firebase Cloud Messaging (Google)

## Batasan

Tidak menggunakan framework atau library CSS/JS/PHP seperti Bootstrap,
Tailwind, React, Vue, Laravel, atau CodeIgniter. Pengecualian yang
diizinkan: php-jwt dan layanan Google.

## Struktur

- `frontend/` — antarmuka HTML, CSS, JavaScript
- `backend/` — API PHP
- `database/` — skema dan seed
- `docs/` — dokumentasi
